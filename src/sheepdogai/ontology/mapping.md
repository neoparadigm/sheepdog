# Mapping: Sheepdog, PROV-O and OpenTelemetry

This table is checked against `sheepdogai.ontology.MAPPING` by `tests/ontology`.

| Sheepdog concept | PROV-O | OTel (gen_ai.*) | Notes |
|---|---|---|---|
| `sheepdogai:Run` | `prov:Bundle` | trace | One per run; carries the policy hash |
| `sheepdogai:ToolCall` | `prov:Activity` | span, gen_ai.operation.name = execute_tool | Start time from the hook; PreToolUse hooks do not see completion |
| `sheepdogai:Agent` | `prov:SoftwareAgent` | gen_ai.agent.id, gen_ai.agent.name | The agent under control |
| `sheepdogai:Policy` | `prov:Plan` | none; use sheepdogai.policy.hash | A versioned rules file plus packs |
| `sheepdogai:Rule` | `prov:Entity` | sheepdogai.rule.id | Member of a policy |
| `sheepdogai:Verdict` | `prov:Entity` | sheepdogai.verdict, sheepdogai.verdict.reason | Generated by the decision, used by the adapter |
| `sheepdogai:Decider` | `prov:SoftwareAgent` | sheepdogai.decider | Rules engine, model or judge |
| `sheepdogai:HumanApproval` | `prov:Activity associated with a prov:Person` | sheepdogai.approval.outcome | Present only when verdict was ask |
| `sheepdogai:Budget` | `prov:Entity` | sheepdogai.budget.* | A constraint; sheepdogai:exceeded links it to the stopping verdict |
| `sheepdogai:Adapter` | `prov:SoftwareAgent` | sheepdogai.adapter | Carries declared capabilities |
| `sheepdogai:LogRecord` | `prov:Entity` | none | Holds prev_hash and hash |
Notes

* OTel `gen_ai.*` names were checked against semantic-conventions **v1.37.0**
  (`sheepdogai.constants.OTEL_GENAI_SEMCONV_VERSION`). They are at *Development* stability and
  may change. The GenAI conventions have since moved to a separate repository
  (`open-telemetry/semantic-conventions-genai`); re-check before bumping the pin. Mapped
  attributes: `gen_ai.operation.name` (= `execute_tool`), `gen_ai.tool.name`,
  `gen_ai.tool.call.id`, `gen_ai.agent.id`, `gen_ai.agent.name`. Everything Sheepdog-specific is
  under `sheepdogai.*`.
* A `PreToolUse` hook fires before the tool runs, so a `ToolCall` has a start time
  (`prov:startedAtTime`) but no end time.
* Extra graph relations used by the exporter and declared in `sheepdogai.ttl`: `sheepdogai:partOf`
  (run membership), `sheepdogai:memberOf` (rule in policy), `sheepdogai:observedBy` (adapter),
  `sheepdogai:priorVerdict` (the rules verdict a Decider received).
