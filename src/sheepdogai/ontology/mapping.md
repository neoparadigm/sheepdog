# Mapping: Sheepdog, PROV-O and OpenTelemetry

This table is checked against `sheepdogai.ontology.MAPPING` by `tests/ontology`.

| Sheepdog concept | PROV-O | OTel (gen_ai.*) | Notes |
|---|---|---|---|
| `sheepdog:Run` | `prov:Bundle` | trace | One per run; carries the policy hash |
| `sheepdog:ToolCall` | `prov:Activity` | span, gen_ai.operation.name = execute_tool | Start time from the hook; PreToolUse hooks do not see completion |
| `sheepdog:Agent` | `prov:SoftwareAgent` | gen_ai.agent.id, gen_ai.agent.name | The agent under control |
| `sheepdog:Policy` | `prov:Plan` | none; use sheepdog.policy.hash | A versioned rules file plus packs |
| `sheepdog:Rule` | `prov:Entity` | sheepdog.rule.id | Member of a policy |
| `sheepdog:Verdict` | `prov:Entity` | sheepdog.verdict, sheepdog.verdict.reason | Generated by the decision, used by the adapter |
| `sheepdog:Decider` | `prov:SoftwareAgent` | sheepdog.decider | Rules engine, model or judge |
| `sheepdog:HumanApproval` | `prov:Activity associated with a prov:Person` | sheepdog.approval.outcome | Present only when verdict was ask |
| `sheepdog:Budget` | `prov:Entity` | sheepdog.budget.* | A constraint; sheepdog:exceeded links it to the stopping verdict |
| `sheepdog:Adapter` | `prov:SoftwareAgent` | sheepdog.adapter | Carries declared capabilities |
| `sheepdog:LogRecord` | `prov:Entity` | none | Holds prev_hash and hash |
Notes

* OTel `gen_ai.*` names were checked against semantic-conventions **v1.37.0**
  (`sheepdogai.constants.OTEL_GENAI_SEMCONV_VERSION`). They are at *Development* stability and
  may change. The GenAI conventions have since moved to a separate repository
  (`open-telemetry/semantic-conventions-genai`); re-check before bumping the pin. Mapped
  attributes: `gen_ai.operation.name` (= `execute_tool`), `gen_ai.tool.name`,
  `gen_ai.tool.call.id`, `gen_ai.agent.id`, `gen_ai.agent.name`. Everything Sheepdog-specific is
  under `sheepdog.*`.
* A `PreToolUse` hook fires before the tool runs, so a `ToolCall` has a start time
  (`prov:startedAtTime`) but no end time.
* Extra graph relations used by the exporter and declared in `sheepdog.ttl`: `sheepdog:partOf`
  (run membership), `sheepdog:memberOf` (rule in policy), `sheepdog:observedBy` (adapter),
  `sheepdog:priorVerdict` (the rules verdict a Decider received).
